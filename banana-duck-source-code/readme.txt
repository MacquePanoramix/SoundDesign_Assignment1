TOOLS YOU WILL NEED
- Love framework (https://love2d.org/)
- LDtk level editor (https://ldtk.io/)
- VScode (optional) (https://code.visualstudio.com/)

HOW TO EDIT THE GAME
- The easiest way to edit and run the game is to use Visual Studio Code (https://code.visualstudio.com/) and setup the right plugins.
Here is the tutorial I followed (https://www.sheepolution.com/learn/book/bonus/vscode).
- The entry point is the main.lua file.
- All game logic are under /res/objects/
- Sprites are under /res/sprite/
- Levels are in /res/ldtk/game.ldtk file, open using LDtk level editor.
